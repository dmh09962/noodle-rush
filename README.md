# Noodle Rush

A pasta restaurant game with Nonna. Play it at https://dmh09962.github.io/noodle-rush/

On a phone, open the link in Safari or Chrome, tap Share, then "Add to Home Screen". The game then opens full screen like an app.

The game lives in `src/` (data, art, game and shop). `python3 build.py` bundles it into `index.html`.
